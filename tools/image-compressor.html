Frequently asked questions

Will every image become smaller?

Not always. The file size depends on the original image, selected format and quality. Compare the new size with the original before downloading.

Do you upload my image?

No. Image processing uses your browser's built-in Canvas API. Your files are not sent to OyunOpti's server.

Does this tool work on mobile?

Yes, on modern mobile browsers. Very large images may run into memory limits.
