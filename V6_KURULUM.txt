KURULUM
1. ZIP'i bilgisayarında çıkar.
2. GitHub > oyunopti > Add file > Upload files.
3. ZIP'in içindeki dosyaların TAMAMINI repo köküne yükle.
4. Commit changes.
5. GitHub Pages güncellendikten sonra Ctrl+F5.
6. Ana sayfada "OyunOpti Rehberleri" bölümünün göründüğünü kontrol et.
7. Üç yeni rehber linkini tek tek aç.
8. sitemap-v4.xml aynı isimde kaldığı için Search Console'a yeni bir sitemap kaydı ekleme. Google mevcut sitemap'i yeniden okuyabilir.
